# مجنونين الساحة — النسخة الأولية 0.1

## الموجود حاليًا
- مشروع Godot 4 ثلاثي الأبعاد.
- ساحة اختبار بسيطة.
- سيارة أولية قابلة للقيادة.
- إنشاء غرفة LAN عبر ENet.
- الانضمام باستخدام IP المضيف.
- حد أقصى 6 لاعبين (مضيف + 5).
- اختيار يدوي بين 3 ساحات اختبار؛ لا يوجد اختيار عشوائي.

## التشغيل
1. افتح المشروع باستخدام Godot 4.3 أو أحدث.
2. شغّل `main.tscn`.
3. على جهاز واحد اضغط «إنشاء غرفة».
4. على بقية الأجهزة المتصلة بنفس Hotspot، أدخل عنوان IP المحلي للمضيف واضغط «انضمام».
5. التحكم بلوحة المفاتيح في هذه النسخة: الأسهم للحركة والاتجاه.

## ملاحظات مهمة
- هذه نسخة تأسيسية تجريبية وليست لعبة مكتملة.
- مزامنة الشبكة أولية وتحتاج اختبارًا وتحسينًا قبل اعتبارها Multiplayer مستقرة.
- واجهة اللمس لأندرويد، نظام التصويت، الصواريخ كل دقيقة، نمط التحول والاختباء، والعربيات النهائية لم تُنفذ بعد.
- لم يتم تشغيل Godot أو اختبار اتصال أجهزة فعلية في بيئة الإنشاء الحالية.
- اخترنا رسوم Compatibility لتسهيل دعم الأجهزة الأضعف.
